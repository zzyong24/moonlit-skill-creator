# 月明·Skill 设计师

从真实任务出发，创建或整理 Agent Skill：理清职责、显式依赖、状态所有权、失败恢复和分发边界。包含轻量只读审计工具，输出问题证据，不自动重写整库。

## 使用

把本目录安装到宿主支持的本地 Skill 目录，避免覆盖同名已有目录；在有版本锁的工作区使用该工程的升级机制。本项目尚未单独公开发布，不提供未经验证的远程安装命令。

自然语言示例：

- “用 moonlit-skill-creator 把这个脚本整理成可分享的 Skill。”
- “审查这些 Skill 的职责和依赖，先不要改。”
- “按审计结果修复，保留已有配置和用户改动。”

无需额外账号或密钥。本地审计需要 Python 3.10+ 标准库，不访问网络，不发送文件内容。外部源码研究由用户提供或明确联网读取；本工具不自动安装或激活第三方依赖。

## 验证

```text
python3 scripts/audit_skills.py <待审查Skill目录>
python3 -m unittest discover -s tests
```

Windows 可用 `py -3`；目前只在 macOS 执行测试，其他系统未实测。审计不等于秘密扫描、行为正确性或效果提升证明。需要规则和来源时由 SKILL.md 按需路由。

Oil 的原始创建 Skill 是可选补充，并非必需依赖；本 Skill 的架构参考与取舍保存在 references/sources.md。
